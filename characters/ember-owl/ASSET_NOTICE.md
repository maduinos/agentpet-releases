# Ember Owl asset notice

`Ember Owl`은 AgentPet의 Claude provider companion을 위해 만든 오리지널 픽셀 아트
캐릭터다. 제3자 이미지나 기존 캐릭터를 입력 참조로 사용하지 않고 2026-07-16에 OpenAI
내장 이미지 생성 도구로 만든 원본 시트에서 8개 상태 포즈를 잘라 투명 PNG로 정리했다.

생성 프롬프트의 핵심 조건은 다음과 같다.

- 따뜻한 테라코타·크림색의 작은 올빼미 사서
- 동일한 외형으로 idle, thinking, editing, running, waiting, approval, success, error 표현
- 고전 RPG풍의 선명한 픽셀 아트와 강한 실루엣
- 로고, 상표, 문자, 워터마크 및 제3자 캐릭터 모사 금지

프로젝트 외부로 배포하거나 특정 제품의 공식 브랜드 자산으로 사용할 때는 저장소
유지보수자가 적용할 라이선스와 브랜드 정책을 별도로 확인한다. 정확한 생성 프롬프트,
원본 hash와 후처리 과정은 `GENERATION.md`에 기록한다.
